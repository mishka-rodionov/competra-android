# Командный зачёт — дизайн-спека

Статус: **согласовано 07.10.2026, к реализации**. Порядок реализации: eSport → Android → web.

## Зачем

Организаторы подводят командный итог по результатам личного первенства: в каждой группе (М16, М18, М21…) и, по желанию, общий — среди мужчин, среди женщин, по всему соревнованию. Сейчас команда — только подпись в протоколе.

## Основные решения

- **Зачёт задаётся абстрактно, на уровне соревнования** — без ссылок на конкретные группы. Поэтому он есть в мастере создания, в «Общем» (web) и в Центре (Android).
- **Хранится одним полем соревнования** `teamScoring` (JSON-объект, `null` — выключен) и синхронизируется вместе с соревнованием, в т.ч. офлайн на Android.
- **Сам зачёт не хранится, а вычисляется** из результатов: сервер — при запросе, Центр на Android — локально (офлайн).
- **Команда — по подписи** `OrienteeringParticipant.commandName`: без учёта регистра, крайних и повторных пробелов (нормализация как у команды при регистрации). Участник без подписи в зачёт не идёт. `teamId` не используется.
- **Очки за место — фиксированная таблица рейтинга** (`RatingPointsTable` в eSport): 1–9 места — 100, 80, 60, 50, 45, 40, 37, 35, 33; 10–40 места — `41 − место`; ниже — 0.

## Настройки (`teamScoring`)

| Поле | Смысл |
|---|---|
| `groupStandings` | зачёт в каждой группе; `null` — нет |
| `groupStandings.method` | `POINTS` (очки за места) / `TIME` (сумма времени) |
| `groupStandings.countedResults` | N — сколько лучших результатов команды в группе |
| `overallScopes` | общие зачёты: набор из `MEN` / `WOMEN` / `ALL` (по полу группы или все группы); пусто — нет |

Общие зачёты строятся из зачётов в группах, поэтому `groupStandings` при включённом зачёте обязателен.

**Умолчания при включении**: зачёт в каждой группе по очкам, N = 3; общие зачёты выключены.

## Зачёт в группе

- `POINTS`: у команды в группе берутся N лучших результатов по очкам за место, итог — сумма. Команда с меньшим числом результатов — в зачёте с тем, что есть.
- `TIME`: N лучших `FINISHED` результатов по `totalTime + penaltyTime`, итог — сумма. Финишировавших меньше N — команда **вне зачёта** (внизу, без места). Недоступен в score-О.

## Общие зачёты — баллы за командные места в группах

- `MEN` — группы с мужским полом, `WOMEN` — с женским, `ALL` — все группы. Группы без пола — только в `ALL`. Пол группы хранится как `M`/`F` (web) или `MALE`/`FEMALE` (Android) — нормализовать.
- За **место команды в зачёте группы** команда получает баллы по той же таблице рейтинга: 1-е место — 100, 2-е — 80, 3-е — 60 и т.д. Поделённое место — одинаковые баллы; команда вне зачёта группы (по времени финишировали меньше N) — 0.
- Итог команды в общем зачёте — сумма этих баллов по группам общего зачёта. Пример: «Азимут» — 1-е место в М16 (100) и 3-е в М21 (60) → среди мужчин 160; у «Компаса» складываются баллы за М16, М18 и М21.
- Одинаково для `POINTS` и `TIME` внутри групп; каждая группа весит одинаково независимо от числа участников, и команда, выступившая в большем числе групп, не проигрывает из-за суммы времени.
- Места по сумме баллов убыв.; при равенстве — сравниваются баллы за группы по убыванию (больше первых мест — выше), затем делят место.
- Отдельного отбора N лучших и ограничения «не больше K из группы» в общем зачёте нет — ограничение задаёт N в каждой группе.

## Общие правила

- В зачёт идут только `FINISHED` с местом; снятые, сошедшие, не стартовавшие, превысившие КВ — 0 очков / не идут.
- Места команд: очки — по сумме убыв., при равенстве сравниваются взятые очки по убыванию (лучший результат, затем второй…), затем делят место; время — по сумме возр., равное — делят место.

## Где показывается

- Результаты (web, Android: детали события, онлайн-результаты, Центр): переключатель **«Личный / Командный»**, в «Командном» — чипы зачётов («Мужчины», «Женщины», «Общий», «По группам»); «По группам» — раздел на каждую группу.
- Строка команды: место, название, итог; раскрывается результатами, вошедшими в зачёт (участник, группа, место, очки/время).
- HTML-протокол (Центр): раздел «Командный зачёт».

## API (eSport)

- `teamScoring` — поле в запросах/ответах соревнования (`null` в запросе — не менять: старые клиенты поле не знают; выключение — явный объект/флаг, уточнить при реализации).
- `GET /api/event/orienteering/competitions/{id}/team-standings` — вычисленные зачёты.

## Аналитика

| Событие | Параметры |
|---|---|
| `create_competition_finished` | + `team_scoring`: `none` / `groups` / `both` (общие зачёты всегда строятся из зачётов в группах, поэтому `overall` без `groups` не бывает) |
| `team_standings_opened` | `competition_id` |

## Не в первой версии

- Своя таблица очков, очки по формуле от числа участников.
- Зачёт по клубу, использование `teamId`.
- Сумма баллов score-О.
- Произвольные наборы групп для общего зачёта (кроме «мужчины / женщины / все»).
- Командный зачёт в рейтинге серии.
