# Предупреждение о несохранённом результате

## Зачем

На экране считывания чипа результат со статусом DSQ и результат после ручной правки отметок не сохраняются сами: организатор проверяет их и нажимает «Сохранить результат». Если по привычке нажать «Назад», экран закрывался без сохранения, а организатор думал, что чип уже записан. Теперь перед выходом появляется предупреждение.

## Как пользоваться (Android)

1. Центр → соревнование → «Сканировать», приложить чип.
2. Если под результатом видна кнопка **«Сохранить результат»** (DSQ, «Засчитать КП», правка или удаление отметки, «Засчитать финиш по времени считывания»), системная кнопка «Назад» не закрывает экран, а показывает диалог **«Результат не сохранён»**:
   - **«Сохранить и выйти»** — результат сохраняется (как по кнопке «Сохранить результат»), экран закрывается;
   - **«Выйти без сохранения»** — экран закрывается, результат не записывается;
   - **«Остаться»** — диалог закрывается, экран остаётся.

Работает во всех соревнованиях, в том числе в режиме [«Регистрация на финише»](../finish-registration/README.md).

## Правила и граничные случаи

- После завершения соревнования экран считывания работает только для просмотра, кнопки «Сохранить результат» нет — предупреждения тоже.
- Если у участника уже есть сохранённый результат, «Сохранить и выйти» показывает обычный диалог конфликта результатов (он общий для приложения и остаётся на экране после выхода).
- Шторки (правка отметки, карточка участника) кнопка «Назад» по-прежнему сначала закрывает.

## Как устроено

- `feature/center/.../read_card/OrientReadCardScreen.kt` — `BackHandler` при `isPendingSave`, диалог `LeaveWithPendingSaveDialog`.
- `OrientReadCardViewModel` — действия `BackPressedWithPendingSave`, `SaveAndLeave` (сохранение через `saveResultFromPending`, затем `navigation.back()`), `LeaveWithoutSaving`, `DismissLeaveConfirm`; флаг `OrientReadCardState.isLeaveConfirmShown`.

## Ограничения и что не вошло

- Переход на другую вкладку нижней навигации и новое считывание чипа поверх несохранённого результата предупреждение не показывают.
