# Редактирование группы участников на сайте

## Зачем

На сайте группы соревнования можно было только добавить или удалить: чтобы поправить контрольное время, лимит участников или число участников в командный зачёт, группу приходилось пересоздавать (и терять привязку участников). В приложении (Центр) редактирование группы было и раньше.

## Как пользоваться

### Web (competra.ru)

1. «Управление» → соревнование → вкладка **«Группы»**.
2. У группы — кнопка **«Изменить»** (рядом с «Удалить»). Открывается тот же диалог, что при добавлении, с заполненными полями и заголовком «Изменить группу».
3. Поменяйте нужное и нажмите **«Сохранить»**.

### Android

Без изменений: группа редактируется в Центре — в мастере или при редактировании соревнования.

## Правила и граничные случаи

- Поля те же, что при добавлении: название, пол, возраст, лимит участников, контрольное время, «Участников в командный зачёт» (если зачёт включён), штраф очками (score-О), дистанция.
- Пол группы, созданной на Android (`MALE` / `FEMALE`), показывается в селекторе как «Мужчины» / «Женщины» и сохраняется в веб-формате `M` / `F` — Android понимает оба.
- Если командный зачёт выключен, поле «Участников в командный зачёт» скрыто и не отправляется — сервер сохраняет прежнее значение.
- Как и при добавлении, вне score-О поля штрафа очками сохраняются пустыми.
- Участники группы, их стартовые времена и результаты при редактировании не меняются. Смена дистанции влияет на проверку отметок при следующем считывании чипа.
- Проверка конфликтов (409) не выполняется: сайт не передаёт `serverUpdatedAt`, побеждает последнее сохранение.

## Как устроено

### Web (`competra-web-ts`)

- `src/features/management/AddGroupDialog.tsx` — режим редактирования через `editingGroup`: поля инициализируются из группы, в запросе — её `groupId` (апдейт существующей строки).
- `src/features/management/ManageGroupsTab.tsx` — кнопка «Изменить», диалог с `key` по группе.
- API без изменений: `POST /api/event/orienteering/save/participantGroup` с существующим `groupId`.
