# Стартовая решётка

## Зачем

Помогает судье на старте: видно, какая стартовая минута идёт сейчас, кто в ней стартует и кто готовится дальше. Минута старта от «нуля» соревнования совпадает с тем, что судьи привыкли видеть в стартовом протоколе (0:01, 0:02, …).

## Как пользоваться

### Android

1. Центр → соревнование → «Стартовая решётка».
2. Вверху — секундомер соревнования (ЧЧ:ММ:СС.сс) и поле «Поиск по номеру» (переход на минуту участника).
3. Пока соревнование запущено, под поиском — подсказка «Следующими стартуют · Ч:ММ»: номера участников минуты, которая стартует следом за текущей. При отметке Sportiduino — номера чипов (в заголовке «· чипы», участник без чипа — «№<стартовый номер>»), при других системах — стартовые номера. Подсказка привязана к реальному времени: ручное листание решётки её не меняет.
4. Ниже — ленточка стартовых минут от «нуля» соревнования (0:00, 0:01, 0:02, …); текущая минута помечена «сейчас», экран сам прокручивается на неё. Ручной свайп отключает автоследование, кнопка «Сейчас» — возвращает.
5. Шапка страницы минуты: «Старт ЧЧ:ММ:СС» (астрономическое время) и число участников. Справа — «до старта ММ:СС» или «стартовали».
6. Список участников минуты: стартовый номер, ФИО, группа, номер чипа.

### Web

Аналога нет.

## Правила и граничные случаи

- «Ноль» — та же база, что у секундомера: фактическое время старта соревнования (`CompetitionStartTimeRepository`), иначе `startTime` соревнования; если и его нет — время первой минуты (она станет 0:00). При старте соревнования стартовые времена участников пересчитываются от этого «нуля», поэтому минута совпадает с протоколом.
- «Текущая» минута — ближайшая нестартовавшая (`currentSlotIndex`): её участники стоят перед судьёй и уходят, когда секундомер дойдёт до её времени. «Следующими стартуют» — минута после неё. Если текущая минута последняя (или все стартовали) — «Следующих стартов нет».
- Номера в подсказке — не больше двух строк, лишнее обрезается многоточием.
- Формат минуты в ленточке — `Ч:ММ` (0:01, 1:15). Если стартовый интервал не кратен минуте — `Ч:ММ:СС` (0:01:30).
- Минута раньше «нуля» показывается со знаком минус.
- Пока «ноль» неизвестен (данные не загружены), в ленточке показывается астрономическое время.
- «до старта ММ:СС» обновляется на границах секунд до ближайшего старта и округляется вверх — одновременно с баннером и [предстартовыми сигналами](../start-signals/README.md).

## Как устроено

### Android (`competra-android`)

- `feature/center/.../data/start_grid/StartGridState.kt` — `StartSlot`, `StartGridState` (в т.ч. `zeroTimeMs`).
- `feature/center/.../presentation/start_grid/StartGridViewModel.kt` — загрузка участников, группировка по минутам, секундомер, вычисление `zeroTimeMs`.
- `feature/center/.../data/start_grid/NextStartHint.kt` — `nextStartSlot` (минута после текущей) и `hintNumbers` (чипы при Sportiduino, иначе стартовые номера); тест — `NextStartHintTest`.
- `feature/center/.../presentation/start_grid/StartGridScreen.kt` — UI (`NextStartHint`), `formatStartMinute`.

## Аналитика

- `CenterStartGridOpened(competitionId)` — открытие экрана.
