# Стартовая решётка

## Зачем

Помогает судье на старте: видно, какая стартовая минута идёт сейчас, кто в ней стартует и кто готовится дальше. Минута старта от «нуля» соревнования совпадает с тем, что судьи привыкли видеть в стартовом протоколе (0:01, 0:02, …).

## Как пользоваться

### Android

1. Центр → соревнование → «Стартовая решётка».
2. Вверху — секундомер соревнования (ЧЧ:ММ:СС.сс) и поле «Поиск по номеру» (переход на минуту участника).
3. Ниже — ленточка стартовых времён; текущая минута помечена «сейчас», экран сам прокручивается на неё. Ручной свайп отключает автоследование, кнопка «Сейчас» — возвращает.
4. Шапка страницы минуты: «Старт ЧЧ:ММ:СС», под ним **«Минута Ч:ММ»** — смещение старта от «нуля» соревнования, затем число участников. Справа — «до старта ММ:СС» или «стартовали».
5. Список участников минуты: стартовый номер, ФИО, группа, номер чипа.

### Web

Аналога нет.

## Правила и граничные случаи

- «Ноль» — та же база, что у секундомера: фактическое время старта соревнования (`CompetitionStartTimeRepository`), иначе `startTime` соревнования; если и его нет — время первой минуты (она станет 0:00). При старте соревнования стартовые времена участников пересчитываются от этого «нуля», поэтому минута совпадает с протоколом.
- Формат минуты — `Ч:ММ` (0:01, 1:15). Если стартовый интервал не кратен минуте — `Ч:ММ:СС` (0:01:30).
- Минута раньше «нуля» показывается со знаком минус.

## Как устроено

### Android (`competra-android`)

- `feature/center/.../data/start_grid/StartGridState.kt` — `StartSlot`, `StartGridState` (в т.ч. `zeroTimeMs`).
- `feature/center/.../presentation/start_grid/StartGridViewModel.kt` — загрузка участников, группировка по минутам, секундомер, вычисление `zeroTimeMs`.
- `feature/center/.../presentation/start_grid/StartGridScreen.kt` — UI, `formatStartMinute`.

## Аналитика

- `CenterStartGridOpened(competitionId)` — открытие экрана.
