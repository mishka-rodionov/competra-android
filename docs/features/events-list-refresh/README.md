# Обновление списка соревнований

## Зачем

Раньше список соревнований загружался только при открытии экрана: чтобы увидеть новое соревнование или сменившийся статус, приходилось уходить с экрана и возвращаться. Теперь список обновляется жестом pull-to-refresh. Тот же жест обновляет кэш «моих стартов» для онлайн-трека без интернета.

## Как пользоваться

### Android

Вкладка «События» → потянуть список вниз. Над списком появляется круглый индикатор, список перезагружается с первой страницы с текущим фильтром. Заодно обновляется список своих соревнований для карточки «Сегодня старт» ([live-track-offline-start](../live-track-offline-start/README.md)). Жест работает и на пустом списке («Соревнований пока нет», «Ничего не найдено»), и на экране ошибки загрузки.

### Web

Отдельного жеста нет — список обновляется перезагрузкой страницы браузера.

## Правила и граничные случаи

- **Индикатор:** при обновлении жестом крутится только индикатор pull-to-refresh, глобальный лоадер на весь экран не показывается. При первом открытии экрана и при смене фильтра — по-прежнему глобальный лоадер.
- **Нет сети:** уже загруженный список остаётся на экране, сбой показывается глобальным диалогом сетевой ошибки. Экран ошибки на весь экран — только если показать нечего.
- **Жест во время первичной загрузки:** загрузка перезапускается, глобальный лоадер скрывается по её окончании.

## Как устроено

**Android** (`competra-android/`):
- `feature/events/.../presentation/main/EventsScreen.kt` — `PullToRefreshBox` (Material 3) вокруг списка; `onRefresh` отправляет `EventsAction.Refresh` и вызывает `LazyPagingItems.refresh()`. Пустое состояние и ошибка обёрнуты в `EventsStateContainer` (`LazyColumn` на всю высоту) — без вложенной прокрутки жест на них не срабатывает.
- `feature/events/.../presentation/main/EventsViewModel.kt` — `onRefreshLoading`: при `EventsState.isRefreshing` не показывает глобальный лоадер, по окончании загрузки сбрасывает флаг и скрывает лоадер.
- `feature/events/.../data/main/EventsPagingSource.kt` — вместо `LoadingRepository` получает коллбэк `onRefreshLoading`, вызываемый только для первой страницы.

## Аналитика

Отдельного события нет — служебное действие без бизнес-эффекта (решение 28.10.2026).
