# Инструкции для организатора

## Зачем

Организатору нужно где-то прочитать, как пользоваться режимами и функциями, которые не очевидны из интерфейса: провести первое соревнование, техстарт без предварительной регистрации, поставить участника вне конкурса, подготовить дистанции в Mapper. Инструкции — HTML-страницы на competra.ru, они открываются из профиля в Android и в web.

## Как пользоваться

- **Android**: «Профиль» → «Дополнительно» → **«Инструкции»** → выбрать инструкцию. Страница открывается в браузере.
- **Web**: «Профиль» → кнопки под меню профиля («Инструкция для организатора», «Инструкция по работе в Mapper», «Соревнование без предварительной регистрации», «Участник вне конкурса»). Страница открывается в новой вкладке.

Инструкции:

| Файл | Название | О чём |
|---|---|---|
| `first-competition-guide.html` | Как провести своё первое соревнование | Весь путь от мастера создания до публикации результатов |
| `finish-registration-guide.html` | Соревнование без предварительной регистрации | Режим [«Регистрация на финише»](../finish-registration/README.md): подготовка чипов и станций, «Открыть старт», карточка незнакомого чипа, неразобранные считывания, исправления, ручной статус, завершение |
| `out-of-competition-guide.html` | Участник вне конкурса | [ВК](../out-of-competition/README.md): где ставить отметку, как выглядит протокол (пример с «ВК» и равным временем 2, 2, 4), что не учитывается, снятие отметки после финиша |
| `mapper-course-planning-guide.html` | Как подготовить дистанции в Mapper | Планирование в Mapper и экспорт IOF XML |

Инструкции ссылаются друг на друга: основная — на две новые (в мастере создания и в разделе про стартовый протокол), новые — на основную и друг на друга.

## Правила и граничные случаи

- Нужен интернет: страницы не встроены в APK, а открываются с сайта. Зато текст правится без релиза приложения — достаточно задеплоить web.
- В Android экран «Инструкции» есть только у авторизованного пользователя (как и весь блок «Дополнительно»), в web — тоже только в профиле вошедшего пользователя.
- Меняешь описанный в инструкции функционал → поправь инструкцию в том же изменении (правило из корневого `CLAUDE.md`).

## Как устроено

- **Web** (`competra-web-ts`): страницы — `public/guides/*.html`, публикуются вместе с сайтом (`https://competra.ru/guides/…`). Стили у всех одинаковые (скопированы из `first-competition-guide.html`; в новых добавлены `.protocol` — таблица-пример протокола и `ol` в этапах). Ссылки — `src/pages/ProfilePage.tsx` (`*_GUIDE_URL`, `ProfileLinks`).
- **Android** (`competra-android`): список — `feature/profile/.../data/GuideLinks.kt` (`Guide`, `GuideLinks.all`, абсолютные URL на competra.ru); экран — `feature/profile/.../presentation/guides/GuidesScreen.kt` (строки `ProfileMenuItem`, `LocalUriHandler.openUri`); маршрут `ProfileNavigation.GuidesRoute` (`:data:navigation`), `ProfileAction.ToGuides`, пункт в `ProfileScreen.kt`; иконка `core/resources/.../drawable/ic_menu_book_24px.xml`.
- Новая инструкция = файл в `public/guides/` + ссылка в `ProfilePage.tsx` + элемент в `GuideLinks.all` + строка в таблице выше.
