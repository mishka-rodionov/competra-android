# Онлайн-трек без интернета

## Зачем

Бегун включает онлайн-трек прямо перед стартом, а там часто нет интернета, и экран деталей соревнования без сети не открывается. Теперь трек включается с вкладки «События» без сети, пишется в телефоне и загружается на сервер, как только появится связь — хоть на дистанции, хоть после финиша.

## Как пользоваться

### Android

1. Заранее, пока есть интернет, зарегистрироваться на соревнование. Список своих соревнований телефон запоминает при открытии вкладки «События», обновлении списка жестом, входе в аккаунт и регистрации.
2. В день соревнования вверху вкладки «События» появляется карточка «Сегодня старт»: название, «Начало в 10:00», кнопка «Начать трек» и подсказка «Можно без интернета — трек загрузится, когда появится связь».
3. «Начать трек» → согласие на публикацию трека (только в первый раз) → разрешения на геолокацию и уведомления → экран «Онлайн-трек». Запись идёт сразу, интернет не нужен.
4. Пока сервер о треке не знает, на экране записи в строке «Передача» — «Нет интернета — трек сохраняется в телефоне и загрузится, когда появится связь» (или «Подключаемся к серверу…»).
5. Во время записи на карточке «Идёт запись трека» и кнопка «Открыть» — экран записи. После остановки, пока трек досылается, — «Трек загружается на сервер».

Кнопка «Включить онлайн-трек» в деталях соревнования работает так же — тоже без обращения к серверу.

### Web

Для зрителя ничего не меняется: трек, загруженный позже, появляется на карте онлайн-треков как обычный (склеивается с другими сессиями участника), загруженный после финиша — в архиве.

## Правила и граничные случаи

- **Карточка «Сегодня старт»** — для соревнований, где сегодня (по часовому поясу соревнования) один из дней проведения и статус не «Завершено»/«В архиве». Без входа в аккаунт и без регистраций карточки нет.
- **Связь появилась на дистанции** — трек регистрируется на сервере, досылается накопленное, дальше идёт онлайн.
- **Связь появилась после финиша** — сервер принимает трек «задним числом»: если результат уже есть или вышло контрольное время, трек сразу попадает в архив, все точки до этого момента сохраняются.
- **Срок** — трек, начатый больше 48 часов назад, сервер не принимает.
- **Отказ сервера** (не зарегистрирован, у группы нет дистанции, слишком старый трек) — точки удаляются, на экране записи «Трек не принят» с причиной.
- **Автоостановка без сети** — запись останавливается сама через `max(6 ч, КВ + 60 мин)` от начала соревнования (или от начала записи, если позже). После связи с сервером действует его срок.
- **Повторное нажатие** при идущей записи продолжает её, новая сессия не создаётся. Новый старт после остановки создаёт новую сессию; на сервере предыдущая активная сессия участника закрывается.
- **Выход из аккаунта** очищает список соревнований на телефоне.

## Как устроено

**API.** `POST /api/live-track/sessions` принимает необязательные `clientSessionId` (UUID сессии, созданной телефоном) и `recordedFrom` (начало записи). Подробности — [спека, раздел 7a](../../specs/live-tracking.md), `competra-server/eSport/docs/API.md`.

**eSport** (`competra-server/eSport/`):
- `src/main/kotlin/tracking/LiveTrackService.kt` — `start`: идемпотентность по `clientSessionId`, `recordingStart` (48 ч), закрытая сразу сессия «задним числом», замена активной сессии участника.
- `src/main/kotlin/tracking/LiveTrackModels.kt` — `StartSessionRequest.clientSessionId/recordedFrom`, `LiveTrackSession.registeredAt`.
- `src/main/kotlin/tracking/LiveTrackTables.kt`, `LiveTrackRepository.kt` — колонка `registered_at`, сторож бездействия от `max(lastPointAt, registeredAt)`.

**Android** (`competra-android/`):
- `domain/.../models/livetrack/MyStart.kt` — соревнование пользователя: `isToday`, `localDeadline`; `domain/.../repository/livetrack/MyStartsRepository.kt`.
- `data/local/.../repository/livetrack/MyStartsRepositoryImpl.kt`, `MyStartDao`, `MyStartEntity` (`my_starts`), миграция 58→59 (`isRegistered`, `rejectMessage` у `live_track_runner_sessions`).
- `core/tracking/.../LiveTrackEngine.kt` — `startOrResume` (сессия на телефоне), регистрация в `uploadStep`; `LiveTrackStarter.kt` — запуск из UI.
- `app/.../service/CompetitionTrackingService.kt` — остановка по `deadlineAt`.
- `feature/events/.../EventsScreen.kt` / `EventsViewModel.kt` — карточка «Сегодня старт», обновление кэша.
- `core/eventdetails/.../live_track_runner/LiveTrackStartUi.kt` — общие диалог согласия и запрос разрешений; `LiveTrackRunnerScreen.kt` — тексты «нет интернета» и «трек не принят».
- `feature/profile/.../AuthInteractor.kt` — обновление кэша при входе, очистка при выходе.

## Аналитика

- `live_track_started(competition_id, is_resumed, source, offline)` — `source`: `details` / `today_card`; `offline` — в момент включения не было интернета.
- `live_track_rejected(competition_id, http_code)` — сервер не принял трек.
- `live_track_stopped` — без изменений; остановка по локальному сроку — `reason = control_time`.

## Ограничения и что не вошло

- Напоминание перед стартом и ярлык на иконке приложения — обсуждались, отложены.
- Если пользователь ни разу не открыл приложение с интернетом после регистрации на сайте, карточки не будет — список соревнований берётся с сервера.
