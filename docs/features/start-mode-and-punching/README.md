# Способ старта и система отметки

## Зачем

При создании соревнования организатор выбирает, чем участники отмечаются на КП («Тип отметки» / «Система отметки») и как стартуют («Способ старта»). Списки урезаны до того, что реально отработано в сценарии проведения, чтобы организатор не выбрал вариант, который приложение не поддерживает.

## Как пользоваться

**Android**: Центр → создание/редактирование соревнования ориентирования → основные поля.
**Web**: «Создать соревнование» → шаг с основными полями; «Управление» → вкладка редактирования соревнования.

- **Тип отметки** (web: «Система отметки») — доступна только **Sportiduino**.
- **Способ старта**:
  - **По стартовому протоколу** — после жеребьёвки судья в «Управлении» запускает старт с обратным отсчётом; после гонга стартовые времена участников пересчитываются от фактического времени старта, участники уходят по жеребьёвке через «Интервал старта».
  - **По стартовой станции** — свободный старт: время старта каждого участника берётся из его отметки на стартовой станции дистанции. «Интервал старта» не показывается, у дистанции обязателен стартовый КП.

Под селектором способа старта — подсказка с кратким описанием обоих режимов.

## Правила и граничные случаи

- Новое соревнование по умолчанию: Sportiduino + «По стартовому протоколу».
- Если у уже сохранённого соревнования стоит скрытое значение (например, «Строгое» или SportIdent), оно остаётся в списке и отображается — при редактировании ничего не сбрасывается молча. Переключиться обратно на скрытое значение после смены нельзя.

## Как устроено

Enum'ы не менялись — скрытие только в UI, контракт с eSport прежний.

- **Android**: `feature/center/.../orientiring_competition_create/CommonCompetitionFieldScreen.kt` — `SUPPORTED_PUNCHING_SYSTEMS`, `SUPPORTED_START_TIME_MODES`; дефолт в `OrienteeringCreatorState` (`USER_SET`); строки `label_start_time_mode*` в `core/resources`.
- **Web** (`competra-web-ts`): `src/features/management/dictionaries.ts` — `punchingSystemOptionsFor(startTimeMode, current)`, `startTimeModeOptionsFor(current)`, `START_TIME_MODE_HINT`; используются в `CreateCompetitionSteps.tsx` и `EditCompetitionTab.tsx`; дефолты в `src/pages/CreateCompetitionPage.tsx`.

| Значение enum | Название в UI |
|---|---|
| `StartTimeMode.USER_SET` | По стартовому протоколу |
| `StartTimeMode.BY_START_STATION` | По стартовой станции |
| `StartTimeMode.STRICT` | Строгое (скрыто) |
| `PunchingSystem.SPORTIDUINO` | Sportiduino |
| `PENCIL`, `PUNCH`, `SFR`, `SPORTIDENT` | скрыты |

## Ограничения и что не вошло

- `STRICT` и системы отметки кроме Sportiduino не отработаны в сценарии проведения; когда появится поддержка — добавить их в `SUPPORTED_*` на обеих платформах.
