# ФИО в регистрациях после смены профиля

## Зачем

При регистрации на соревнование фамилия и имя копируются из профиля в строку участника — так в протоколе остаётся имя, под которым человек бежал. Если участник поменял фамилию в профиле (например, после свадьбы) до старта, в списке участников оставалось старое ФИО. Теперь смена ФИО в профиле переносится в регистрации на ещё не стартовавшие соревнования.

## Как пользоваться

Ничего отдельно делать не нужно: поменяйте фамилию или имя в профиле.

- **Android** — «Профиль» → редактирование профиля → «Сохранить».
- **Web (competra.ru)** — «Профиль» → **«Редактировать профиль»** → **«Сохранить»**.

После сохранения в списке участников и стартовом протоколе соревнований, которые ещё не начались, будет новое ФИО.

## Правила и граничные случаи

- **Прошедшие и идущие соревнования не меняются.** Обновляются только регистрации на соревнования, которые ещё не стартовали: статус не `IN_PROGRESS`/`FINISHED`/`ARCHIVED` и время старта не наступило (`isCompetitionStarted`).
- **Правку организатора не перетираем.** Строка обновляется, только если её ФИО всё ещё совпадает со *старым* ФИО профиля — без учёта регистра, ё/е и лишних пробелов. Если организатор уже исправил фамилию вручную (или поменял местами имя и фамилию), строка остаётся как есть.
- **Записались под другим именем.** Если при регистрации профиль был без ФИО и имя вводилось в диалоге вручную, оно со старым ФИО профиля не совпадает — такая регистрация не обновится. Поправить её может организатор.
- **Пустое ФИО.** Если новое имя или фамилия пустые, регистрации не трогаются.
- **Участники, добавленные организатором** без привязки к аккаунту, не затрагиваются: обновляются только строки с `user_id` пользователя.

## Для организатора

- В «Центре» на Android новое ФИО появится после синхронизации: у строки участника обновляется `updated_at`.
- Если в это время у организатора есть несинхронизированная правка того же участника, сервер ответит 409 и победит серверная версия (общее правило server-wins).
- Исправить ФИО участника вручную по-прежнему можно: Android — список участников, иконка карандаша; web — «Управление» → «Участники» → «Изменить».

## Как устроено

### eSport

- `PATCH /api/user/profile` (`src/main/kotlin/data/database/Databases.kt`) после сохранения профиля вызывает `OrienteeringParticipantService.syncRegistrationNames(userId, старое ФИО, новое ФИО)`.
- `src/main/kotlin/data/services/OrienteeringParticipantService.kt` — `syncRegistrationNames`: выбирает строки `orienteering_participants` с этим `user_id`, оставляет совпадающие со старым ФИО на нестартовавших соревнованиях, пишет новые `first_name`/`last_name` и `updated_at`.
- `src/main/kotlin/data/services/NameMatching.kt` — чистая функция `isRegistrationNameFromProfile`. Тесты — `src/test/kotlin/data/services/NameMatchingTest.kt`.

Изменений в API-контракте и в клиентах (Android, `competra-web-ts`) нет.
