# Командный зачёт

## Зачем

Командный итог по результатам личного первенства: зачёт команд в каждой группе (М16, М18, М21…) и, по желанию, общий — среди мужчин, среди женщин, по всему соревнованию. Команда — подпись участника в протоколе. Дизайн и решения — [docs/specs/team-scoring.md](../../specs/team-scoring.md).

## Как пользоваться

### Android

1. **Включить**: «Центр» → создание соревнования (или его редактирование) → «Общее», под «Контрольным временем» — переключатель **«Командный зачёт»**. По умолчанию: зачёт в каждой группе **«По очкам за места»**, **«Сколько участников в зачёт»** — 3, общих зачётов нет.
2. **«Зачёт в каждой группе»** — «По очкам за места» или «По сумме времени» (в score-О — только очки). **«Сколько участников в зачёт»** — N.
3. **«Общие зачёты»** — чипы «Мужчины», «Женщины», «Общий».
4. **Смотреть**: результаты в Центре, результаты и онлайн-результаты в деталях события — переключатель **«Личный / Командный»** над группами (виден, если зачёт включён). В «Командном» — чипы общих зачётов и «По группам»; нажатие на команду раскрывает участников (не вошедшие в зачёт — серым).
5. **HTML-протокол** («Опубликовать результаты» в Центре) — раздел «Командный зачёт» после личных результатов.

### Web (competra.ru)

1. **Включить**: мастер создания → «Основное», под «Контрольным временем» — галочка **«Командный зачёт»**; у существующего — «Управление» → «Общее». Поля те же, что на Android: «Зачёт в каждой группе», «Сколько участников в зачёт», «Общие зачёты» (кнопки «Мужчины», «Женщины», «Общий»).
2. **Смотреть**: страница соревнования → «Результаты» → переключатель **«Личный / Командный»** (виден, если зачёт включён). В «Командном» — кнопки общих зачётов и «По группам»; нажатие на команду раскрывает участников.

## Правила и граничные случаи

- **Команда** — подпись участника без учёта регистра, крайних и повторных пробелов: «Азимут», « азимут » и «АЗИМУТ» — одна команда. Участник без подписи в зачёт не идёт.
- **Зачёт в группе, очки за места**: участник получает очки за место по таблице рейтинга (1–9 места — 100, 80, 60, 50, 45, 40, 37, 35, 33; 10–40 — `41 − место`; ниже — 0); у команды складываются N лучших. Команда с меньшим числом результатов — в зачёте с тем, что есть; команда без единого места (все сняты) — вне зачёта.
- **Зачёт в группе, сумма времени**: N лучших времён (с учётом штрафного времени); финишировавших меньше N — команда вне зачёта, внизу без места.
- **Равенство**: по очкам — сравниваются слагаемые по убыванию (лучший результат, затем второй…), полностью равные — делят место; по времени — равная сумма делит место.
- **Общие зачёты** («Мужчины», «Женщины», «Общий»): команда получает баллы за своё командное место в каждой группе по той же таблице (1-е — 100, 2-е — 80…), баллы складываются. Пол группы — «Мужчины»/«Женщины»; группы без пола — только в «Общем». Вне зачёта группы — 0.
- Снятые, сошедшие, не стартовавшие и превысившие КВ в зачёт не идут (в списке команды — серым).
- Командный зачёт не хранится, а вычисляется из текущих результатов — правка результата сразу меняет зачёт.

## Как устроено

### Данные (eSport)

- `orienteering_competitions.team_scoring` — настройки JSON-ом (`groupMethod` POINTS/TIME, `groupCountedResults` N, `overallScopes` MEN/WOMEN/ALL); `null` — зачёта нет.

### API

| Метод | Путь | Что делает |
|---|---|---|
| POST 🔒 | `/api/event/orienteering/save/competitions` | `teamScoring` в `OrienteeringCompetitionRequest`: `null` — не менять (старые клиенты), `{enabled: false}` — выключить, `{enabled: true, groupMethod, groupCountedResults, overallScopes}` — включить |
| GET | `/api/event/orienteering/competitions/{id}/team-standings` | Вычисленный зачёт (`TeamStandingsResponse`): `groupStandings` — по группам (команды с местом, суммой очков/времени и участниками, `counted` — вошёл ли в зачёт), `overallStandings` — общие; `result = null`, если зачёт не включён |

Настройки отдаются в `teamScoring` у `OrienteeringCompetitionResponse` и `CompetitionDetailResponse`.

### eSport

- `src/main/kotlin/domain/orienteering/TeamScoring.kt` — модель настроек.
- `src/main/kotlin/data/services/TeamStandings.kt` — `computeTeamStandings`: чистая функция подсчёта; тесты — `src/test/kotlin/data/services/TeamStandingsTest.kt`.
- `src/main/kotlin/data/services/TeamScoringJson.kt` — хранение/разбор настроек, семантика `null` / `enabled = false`.
- `src/main/kotlin/data/services/TeamStandingsService.kt`, маршрут в `data/routing/OrienteeringRouting.kt`.
- Таблица очков — `src/main/kotlin/data/util/RatingPointsTable.kt` (общая с рейтингом).

### Android

- `domain/.../orienteering/TeamScoring.kt` — настройки, `placePoints` (таблица рейтинга); `TeamStandings.kt` — `computeTeamStandings`, тот же алгоритм, что в eSport (тесты — `domain/src/test/.../TeamStandingsTest.kt`).
- `OrienteeringCompetition.teamScoring`; Room — колонка `teamScoring` строкой «метод|N|области» (`CompetitionConverters`), миграция 54→55; синхронизация — вместе с соревнованием, Android шлёт поле всегда (`{enabled: false}` при выключенном).
- Зачёт считается на устройстве: Центр — из локальной БД (офлайн), детали события — из загруженных результатов; эндпоинт `team-standings` Android не использует.
- UI: `feature/center/.../TeamScoringBlock.kt` (настройки), `core/ui/.../TeamStandingsContent.kt` (`TeamStandingsContent`, `ResultsModeToggle`), экраны результатов в `feature/center` и `core/eventdetails`, HTML — `buildTeamStandingsHtml` в `OrienteeringCompetitionResultsViewModel`.

### Web (`competra-web-ts`)

- `src/types/teamStandings.ts`, `src/lib/teamScoring.ts` (умолчания, запрос с `{enabled: false}` для выключенного, значение для аналитики).
- `src/features/management/TeamScoringFields.tsx` — настройки в мастере (`CreateCompetitionSteps.tsx`) и «Общем» (`EditCompetitionTab.tsx`).
- Показ — `src/features/competition-detail/TeamStandingsView.tsx` (данные с сервера, `useTeamStandings`, во время старта обновляется вместе с результатами), переключатель — в `ResultsTab.tsx`.

## Аналитика

| Событие | Параметры |
|---|---|
| `create_competition_finished` | + `team_scoring`: `none` / `groups` / `both` |
| `team_standings_opened` | `competition_id` — при включении «Командного» в результатах Центра и деталей события (онлайн-результаты — без события) |

## Ограничения и что не вошло

- Своя таблица очков, зачёт по клубу (`teamId`), сумма баллов score-О, произвольные наборы групп, командный зачёт в рейтинге серии.
