# Карта онлайн-треков (зритель)

## Зачем

Зритель (в том числе гость) смотрит на карте дистанции, где сейчас участники, а после соревнования — их сохранённые треки: может проиграть забег, сравнить участников и раскрасить трек по скорости. Устройство трекинга целиком (запись у бегуна, сервер, изоляция) — в спеке [`docs/specs/live-tracking.md`](../../specs/live-tracking.md); здесь — только экран просмотра.

## Как пользоваться

**Android**: событие → «Онлайн-треки» → дистанция. На экранах деталей события и списка дистанций «Онлайн-треки» тоже есть стрелка «назад» в шапке.
**Web**: страница события → вкладка «Онлайн-треки» → дистанция (`LiveTrackMapPage`).

Экран полноэкранный: на Android нижняя навигация на нём спрятана, выход — стрелкой «назад» слева в шапке (или системным «назад»). В шапке — название дистанции и сводка: «На дистанции: N • треков: M», «Архив треков: M» или «Пока нет треков».

- **Фильтры** (чипы под шапкой): «Хвост 5 мин» (только последние 5 минут трека), «Просмотр» (появляется, когда есть завершённые треки), «Скорость» (раскраска трека: красный — медленно, зелёный — быстро) и группы дистанции.
- **Карта**: растр карты дистанции поверх OSM, КП, треки и маркеры с номерами участников.
- **Просмотр**: ▶/пауза, ползунок и время; «Общий старт» / «Реальное время» и скорость ×N. Галочками в списке выбираются участники для сравнения.
- **Список участников**: цвет трека, №, имя, группа и статус («на дистанции», «нет данных N мин», «финиш»…). Нажатие показывает участника на карте, в режиме «Скорость» — оставляет только его трек.

### Ориентация экрана

Android и web раскладывают экран одинаково.

- **Вертикально**: шапка → фильтры → карта (~62% высоты) → панель просмотра → список (~38%).
- **Горизонтально** (Android — ширина больше высоты, в т.ч. планшет; web — альбомная ориентация окна шириной от 600 px, в т.ч. ноутбук): слева панель шириной 40% экрана (Android 280–400 dp, web 280–400 px) — шапка со стрелкой «назад», фильтры, настройки просмотра («Общий старт» / «Реальное время», ×N) и список участников; справа на всю высоту — карта, под ней ▶/ползунок/время (ползунок во всю ширину карты).
- Android: экран сам отступает от системных панелей и выреза камеры (`safeDrawing` по бокам и снизу), поэтому в горизонтальной ориентации ничего не уходит под кнопки навигации.

## Правила и граничные случаи

- Нет связи с сервером треков — в шапке «Нет связи с сервером треков — показаны последние данные», на карте остаются последние точки.
- Опрос сервера идёт, только пока экран виден (web — пока вкладка браузера не скрыта).
- Android: при повороте экрана карта пересоздаётся и заново вписывает карту дистанции. Web: Leaflet при повороте только пересчитывает размер, центр и масштаб остаются прежними.

## Как устроено

- **Android**:
  - `core/eventdetails/.../presentation/live_tracks/LiveTrackMapScreen.kt` — экран: `PortraitLayout` / `LandscapeLayout` (выбор по `maxWidth > maxHeight` в `BoxWithConstraints`), `MapHeader` со стрелкой «назад», `ReplayControls` + `ReplayOptions`, карта на osmdroid.
  - `LiveTrackMapViewModel.kt` — опрос, просмотр, раскраска; `LiveTrackMapAction.Back` → `Navigation.back()`.
  - `app/.../presentation/main/MainActivity.kt` — `NavDestination.isFullScreen()`: список маршрутов, на которых `MainScreen` прячет нижнюю навигацию (сейчас `EventsNavigation.LiveTrackMapRoute`). Решение принимается по текущему маршруту активного таба.
- **Web** (`competra-web-ts`): `src/pages/LiveTrackMapPage.tsx` — страница на весь экран (`h-dvh`) со своей кнопкой «назад»; карта на Leaflet. Раскладка — CSS-сетка `.live-track-layout` в `src/index.css` (области `header` / `filters` / `map` / `controls` / `options` / `list`, у элементов `[grid-area:…]`); на широком экране сетка перестраивается в две колонки, там же вариант `landscape-wide:` для точечных стилей (рамка у карты, список без ограничения высоты).

## Аналитика

- `LiveTrackMapOpened(competitionId, distanceId, mode)` — открытие карты, `mode` = `LIVE` / `ARCHIVE`.
