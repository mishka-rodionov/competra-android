# Завершение регистрации

## Зачем

Регистрация на соревнование закрывается в дату окончания регистрации или раньше, если организатор завершил её вручную. После этого участник не может ни зарегистрироваться, ни отменить регистрацию: стартовый протокол уже составляется, а отмена «задним числом» вернула бы отменённого участника в протокол организатора, если тот правит его офлайн.

## Как пользоваться

**Организатор (Android)**: Центр → соревнование → управление → «Завершить регистрацию» → подтвердить в диалоге «Завершить регистрацию?». После этого кнопки нет: регистрация закрыта.

**Участник** — экран деталей соревнования:

- **Android** (вкладка «События» → соревнование): под датой написано «Регистрация закрыта». Кнопки «Зарегистрироваться» нет. Если пользователь уже зарегистрирован — «Вы зарегистрированы» и «Регистрация завершена — отменить её уже нельзя», без кнопки «Отменить регистрацию». На экране группы кнопки «Зарегистрироваться» тоже нет.
- **Web** (страница соревнования → «Группы»): кнопок «Зарегистрироваться» у групп нет; зарегистрированному — «Вы зарегистрированы» и «Регистрация завершена — отменить её уже нельзя».

До открытия регистрации (статус `CREATED`) на Android написано «Регистрация откроется ДД.ММ.ГГГГ», кнопки «Зарегистрироваться» нет — как в вебе. Уже зарегистрированный (организатор перенёс начало регистрации на будущее) может отменить регистрацию — сервер это разрешает.

## Правила и граничные случаи

- Состояние регистрации определяет статус соревнования с сервера. eSport вычисляет его при каждом чтении по датам (`computeEffectiveStatus`): после `registrationEnd` — `REGISTRATION_CLOSED`, после времени старта — `IN_PROGRESS`. Фоновый шедулер обновляет сохранённый статус с задержкой до 5 минут, но клиенты получают уже пересчитанный.
- Отмену регистрации после закрытия eSport отклоняет с HTTP 409 (`cancelRegistration`), даже если клиент её отправит.
- Участники, отменившие регистрацию в вебе, удаляются из локального протокола Android при следующем pull (`planServerMerge`).

## Для организатора

Досрочное закрытие — это `registrationEnd = now` и статус `REGISTRATION_CLOSED`, отдельного флага нет. Чтобы редактор соревнования не пересчитал дату окончания от даты старта и не открыл регистрацию снова, на Android используется режим `RegistrationEndMode.CLOSED_BY_ORGANIZER`.

## Как устроено

- **eSport**: `data/services/CompetitionStatus.kt` (`computeEffectiveStatus`), `data/services/OrienteeringParticipantService.kt` (`cancelRegistration` → 409), шедулер в `data/services/OrienteeringCompetitionService.kt`.
- **Android**:
  - Организатор: `OrienteeringEventControlViewModel` (закрытие: `registrationEnd = now`, `CompetitionStatus.REGISTRATION_CLOSED`), `RegistrationSection` в `OrienteeringEventControlScreen.kt`.
  - Участник: `EventStatus.REGISTRATION_CLOSED` в `:domain` (`models/events/EventStatus.kt`); `CyclicEventDetailsRepositoryImpl.mapStatus` переводит серверный `REGISTRATION_CLOSED` в него. `EventActionButtons` в `core/eventdetails/.../details/EventDetailsScreen.kt` показывает «Зарегистрироваться» только при `EventStatus.REGISTRATION`, «Отменить регистрацию» — при `CREATED` и `REGISTRATION`; `EventParticipantGroupScreen` — тоже только при `REGISTRATION`.
- **Web** (`competra-web-ts`): `src/pages/CompetitionDetailPage.tsx` передаёт `registrationOpen = status === 'REGISTRATION_OPEN'` в `src/features/competition-detail/GroupsTab.tsx`.

## Аналитика

- `registration_close_clicked(competition_id)` — организатор завершил регистрацию (Android).

## Ограничения и что не вошло

- В вебе кнопки «Завершить регистрацию» нет — только в Android.
- Статус на открытом экране не пересчитывается сам: если дедлайн наступил, пока экран открыт, кнопка исчезнет после обновления экрана. Попытка регистрации в этот момент завершится ошибкой сервера.

## История

- **24.09.2026** — «Завершить регистрацию» в Android, запрет отмены после закрытия в eSport и web, удаление отменивших участников при pull.
- **13.11.2026** — Android: серверный статус `REGISTRATION_CLOSED` превращался в `CREATED`, и на экране деталей была кнопка «Зарегистрироваться» рядом с надписью «Регистрация закрыта». Добавлен `EventStatus.REGISTRATION_CLOSED`; кнопки регистрации и отмены — только при открытой регистрации, как в вебе.
