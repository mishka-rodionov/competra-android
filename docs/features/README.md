# Features

Документация по реализованным фичам: как фича выглядит для пользователя (Android и web) и как она устроена внутри. В отличие от [specs](../specs/) (дизайн до реализации), здесь — описание того, что **реально сделано и работает**.

Документация пишется **вместе с реализацией фичи** — в том же изменении, что и код. Правило и триггер — в корневом [CLAUDE.md](../../CLAUDE.md).

## Структура

Одна фича — одна подпапка `docs/features/<feature-name>/` (kebab-case). Внутри минимум `README.md`; скриншоты, схемы и вспомогательные файлы кладутся рядом.

Фичи общие для всей экосистемы (Android, `competra-web-ts`, backend `eSport`), поэтому документация живёт здесь одна на все платформы. Платформенные отличия описываются внутри документа.

## Шаблон `README.md`

1. **Зачем** — какую задачу решает фича, 2–3 предложения.
2. **Как пользоваться** — сценарии по шагам для Android и web: где находится, что пользователь видит, что нажимает. Тексты элементов интерфейса — как в приложении.
3. **Правила и граничные случаи** — что происходит в нестандартных ситуациях (нет сети, нет прав, данные изменились и т.п.).
4. **Для организатора** — если фича затрагивает управление соревнованием.
5. **Как устроено** — модель данных, API, ключевые файлы по репозиториям (пути относительно корня каждого репо).
6. **Аналитика** — события и параметры.
7. **Ограничения и что не вошло** — осознанно отложенное.
8. **История** — даты и что менялось.

Если раздел не применим — пропусти его, не пиши «нет».

## Фичи

- [registration-team](registration-team/README.md) — команда участника при регистрации на соревнование: автоподстановка клубной команды, подсказки, «такой клуб есть в Competra».
- [choice-min-controls](choice-min-controls/README.md) — «по выбору» с минимумом КП: места по времени, обязательные КП, правила задаются на дистанции (в т.ч. из Mapper).
- [start-mode-and-punching](start-mode-and-punching/README.md) — способ старта («По стартовому протоколу» / «По стартовой станции») и система отметки (только Sportiduino) при создании соревнования.
- [team-scoring](team-scoring/README.md) — командный зачёт: в каждой группе (очки за места / сумма времени) и общие — мужчины, женщины, все.
- [live-track-viewer](live-track-viewer/README.md) — карта онлайн-треков для зрителя: фильтры, просмотр, раскраска по скорости, раскладки в вертикальной и горизонтальной ориентации.
- [group-editing](group-editing/README.md) — редактирование группы участников на сайте («Управление» → «Группы» → «Изменить»).
- [late-entry](late-entry/README.md) — дозаявка после жеребьёвки: опоздавший встаёт в ближайшую свободную минуту по правилам жеребьёвки, в конец протокола или на время, введённое вручную.
