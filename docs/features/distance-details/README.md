# Подробности дистанции

## Зачем

После создания дистанции вручную или импорта IOF XML из Mapper организатор видел на карточке только длину, набор и число КП — нельзя было проверить, что дистанция загрузилась правильно: в каком порядке КП и дошли ли до сервера их координаты. Теперь по клику на дистанцию открываются подробности, а в мастере создания соревнования видно, какие КП в выбранном XML-файле.

## Как пользоваться

### Web

**Вкладка «Дистанции» в управлении соревнованием.**

1. «Управление» → соревнование → вкладка «Дистанции».
2. Нажмите на верхнюю часть карточки дистанции (название, «Длина», «КП» — справа стрелка «›»).
3. Откроется окно с названием дистанции:
   - длина, набор, число КП, описание; для «по выбору» с минимумом КП — «Взять N из M КП»;
   - сводка о координатах (см. «Правила»);
   - таблица: «Старт», КП по порядку (порядковый номер и номер КП), «Финиш». Номер у старта — стартовое КП (режим «По стартовой станции»), у финиша — финишное КП;
   - колонка «Координаты»: ✓ — координаты загружены (сами числа — во всплывающей подсказке при наведении), жёлтое «нет координат» — нет;
   - колонка «Перегон» — расстояние по прямой от предыдущей строки, и итог «По прямой через все КП: X м · длина дистанции — Y м» — если хватает координат;
   - в score-О — колонка «Баллы», в «по выбору» — пометка «обяз.» у обязательных КП и подсказка «Порядок свободный».
4. «Закрыть», «×» или клик мимо окна — закрыть.

**Мастер создания соревнования, шаг «Дистанции».**

- Под выбранным IOF XML-файлом — каждая его дистанция: «М21 — 6754 м, КП: 18» и строкой ниже номера КП по порядку («31 → 32 → 33»; в «по выбору» — через запятую).
- Клик по дистанции, добавленной вручную, открывает то же окно — с порядком КП (координат и перегонов у таких дистанций нет).

## Правила и граничные случаи

- **Сводка о координатах:**
  - есть у всех — «Координаты загружены у старта, финиша и всех КП. По ним считаются длины перегонов и темп в сплитах, а КП видны на карте онлайн-треков.»;
  - есть не у всех — жёлтым «Нет координат: старт, КП 34, 35, финиш. На этих перегонах не посчитаются длина и темп в сплитах — провести соревнование это не мешает.»;
  - нет ни у одного (дистанция создана вручную) — нейтрально «Координат нет — …», колонка «Координаты» не показывается.
- Отсутствие координат — **предупреждение (жёлтый, токен `warning`), а не ошибка (красный)**: провести соревнование без них можно. Красным — только дистанция без единого КП.
- Окно на вкладке открывается только организатору (на странице управления). На публичной странице соревнования карточка не кликабельна: до старта бэкенд и так не отдаёт не-организаторам координаты (см. [distance-map-visibility](../distance-map-visibility/README.md)), а порядок КП участнику до старта не нужен.
- В «по выбору» порядка нет — перегоны и итог по прямой не считаются, КП показаны в том порядке, как записаны в дистанции.
- Перегон считается, только если координаты есть у обоих концов; итог по прямой — только если хватает координат на всех перегонах.
- В мастере превью XML — только номера КП из файла: координаты и перегоны там не показываются, потому что файл разбирает и сохраняет сервер уже при публикации. Проверить, что сохранилось, — на вкладке «Дистанции» после создания.

## Как устроено

Данные окна на вкладке — уже загруженный список `GET /api/event/orienteering/distances?competitionId=…`, новых запросов нет.

**Web** (`competra-web-ts/`):
- `src/features/management/DistanceDetailsDialog.tsx` — окно подробностей: строки «Старт / КП / Финиш», сводка координат, перегоны. Принимает `DistanceDetails` — общее подмножество `Distance` и `PendingDistance` (дистанции мастера).
- `src/features/competition-detail/DistancesTab.tsx` — `DistanceCard`: верх карточки (`DistanceSummary`) — кнопка, открывающая окно, если `canEditMap` (организаторский режим).
- `src/features/management/CreateCompetitionSteps.tsx` (`DistancesStep`) — номера КП в превью XML, клик по ручной дистанции.
- `src/features/management/types.ts` — `parseXmlCoursePreviews` через `DOMParser`: номера КП по тем же правилам, что `IOFXmlParser.kt` в eSport (без старта и финиша, номер — цифры из ссылки на КП). Это только превью: меняешь разбор КП в eSport — поправь и его.
- `src/lib/splitsTable.ts` — `controlPointDistanceMeters` (haversine) — то же расстояние, по которому считается темп на перегонах в сплитах.
- `src/index.css` — токен `--color-warning` (`text-warning`) в дизайн-системе «Лес».

## Ограничения и что не вошло

- КП на карте в окне не показываются.
- В Android аналога нет.
- Новых событий аналитики нет.
